# Machine Health Monitor

## Overview
This Python script uniquely identifies a machine, diagnoses system health, and suggests fixes for common performance issues.

## Features
- **Machine Identification**: Retrieves a unique identifier (UUID).
- **System Health Check**: Monitors CPU and memory usage.
- **Issue Fix Suggestions**: Provides recommendations for high resource usage.

## Requirements
Ensure you have Python installed along with the necessary dependencies:
```bash
pip install psutil
Usage
Run the script to check system health and receive improvement suggestions:
python machine_health_monitor.py
